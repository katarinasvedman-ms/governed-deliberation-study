# Predecessor documentation archive

These documents and presentations come from
[agentic-harness-validation](https://github.com/katarinasvedman-ms/agentic-harness-validation).
They explain the original governed incident-remediation demo, including its
React console, backend-for-frontend, and deployment ambitions. They are retained
as historical context, not the scope, current status, or roadmap of this study.

| Document | Historical subject |
| --- | --- |
| [PRD](PRD.md) | Product goals and planned capabilities |
| [FRD](FRD.md) | Functional requirements for the original demo |
| [Demo guide](DEMO_GUIDE.md) | Mock console and local backend rehearsal |
| [Operations runbook](OPERATIONS_RUNBOOK.md) | Operating the inherited demo |
| [Release and deployment](RELEASE_DEPLOYMENT.md) | Hosted release preparation |
| [Governance presentation](agent-governance-presentation.html) | Enterprise portfolio governance |
| [Architecture presentation](agentic-harness-architecture.html) | Original runtime and platform mapping |

Source code, tests, schemas, data, and deployment configuration have not been
moved. Archived command examples are historical and are run from the repository
root where indicated; they are not instructions to deploy the research study.

The [verification specification](../VERIFICATION_SPEC.md),
[guarantee report](../GUARANTEE_REPORT.md), [threat model](../THREAT_MODEL.md),
and [integration ADR](../adr/0001-copilot-sdk-inner-loop.md) remain in place
because they provide active baseline evidence or integration context.
The report and specification paths are also consumed by existing scripts.
Small compatibility pages at `docs/PRD.md` and `docs/FRD.md` preserve the
verification specification's original references without changing its hashed
content.

Use the [current README](../../README.md) for the research overview.
